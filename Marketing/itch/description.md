# Concept Wars — itch.io page kit

## Short description (itch "tagline", max ~100 chars)

Command a squad of Concept Spirits in a pixel-art bullet-hell where every unit is an idea come to life.

## Classification / tags

- **Genre:** Shooter (secondary: Action, Strategy)
- **Tags:** bullet-hell, shoot-em-up, pixel-art, anime, gacha, story-rich, team-building, singleplayer, 2d, browser
- **Input:** Keyboard (Mouse for menus)
- **Platform:** HTML5 (WebGL) — runs in the browser

## Page description and theme

- **Description:** paste `description.html` into *Edit game → Description*
  (switch the editor to HTML / source mode first).
- **Custom CSS:** paste `itch-custom.css` into *Edit theme → CSS*.
  If itch strips the Google Fonts `@import`, pick **Silkscreen** (headings)
  and **Pixelify Sans** (body) in the theme editor's font menus.
- In the theme editor, set the page background to `#050d16` so the edges match.
